# Community Leaderboard Submissions

This directory contains standardized benchmark submission bundles.

## Submission Structure

Submissions are structured by organization and model:
```
submissions/
└── <organization_or_researcher>/
    └── <model_or_agent>/
        ├── submission.json
        ├── manifest.json
        ├── metrics.json
        └── submission_bundle.zip
```

See [docs/SUBMITTING_RESULTS.md](../docs/SUBMITTING_RESULTS.md) for full submission and validation instructions.
